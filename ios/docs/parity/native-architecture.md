# The native rebuild: how the pieces fit

The owner's decision: the iPhone app rebuilds every Maham One web screen **natively in
Swift**, looking and working exactly like the web app on a phone. Maham Tasks follows
later, the same way. The blueprints are in this folder:

- `mobile-design.md`: the shell, the tokens and the components.
- `data-layer.md`: how records are read and written.
- `business-logic.md`: the rules to port.
- `screens.md`: every screen.

## Principles

1. **The web is the reference.** When in doubt, read the web code and do what it does. The
   wording is the web's own: the same English keys and the same Arabic (generated from
   `src/i18n/ar`).
2. **Records stay raw.** Every record is a `JSONValue` (`MahamKit/Records`) and goes back to
   the server whole, unknown fields included. Typed views read from it and write into it;
   they never rebuild a record from scratch.
3. **Identical results or no write.** The web's devices recompute totals, statuses and stock,
   and rewrite whatever differs. So the app writes a kind of record only once its rules are
   ported **and** tested against the web's own test cases. The sync engine keeps an
   allowlist of writable record kinds, empty until then.
4. **Generated, not copied.** Themes, icons and Arabic strings are generated from the web
   sources by scripts in `scripts/`. Run them again when the web changes.

## Where the code lives

### `ios/MahamKit` (Swift package; builds and tests on Linux and macOS)

| Folder | Holds |
|---|---|
| `Sources/MahamKit/Records/` | `JSONValue`, the typed views over records, `ids` (`newId`, `shortId`, `stableId`, ported bit for bit), `known` |
| `Sources/MahamKit/Foundation/` | `money`, `dates`, `format`, `words`, `kuwait`, `kuwait-rules`, `geo`, `units`, `numbering`, `defaults` |
| `Sources/MahamKit/Access/` | the port of `src/cloud/roles.ts`: what each role may see and change |
| `Sources/MahamKit/Sync/` | the local mirror, pull, outbox, push, the company patch, `reserve_number`, privacy filtering, features and permissions |
| `Sources/MahamKit/Books/`, `People/`, … | the domain rules, ported per stage |
| `Tests/MahamKitTests/` | ports of the web's own test cases, named after the web test file |

### `ios/App` (the iPhone app)

| Folder | Holds |
|---|---|
| `DesignSystem/` | the generated themes, `ThemeStore` (light / dark / system, one theme each, saved), the fonts, the lucide icons, and components named after the web's (`Button`, `Card`, `Badge`, `Field`, `ListCard`, `PageHeader`, `EmptyState`, `Segmented`, `Dialog`, `Menu`, `Toast`, `Spinner`, `StickyActions`, `DateField`, `Combobox`) |
| `Localization/` | `t(_:_:)`, `tp(_:_:_:)` and `interpolate`, matching `src/i18n/index.ts`; `LanguageStore` (English / Arabic, switchable in the app as on the web); right-to-left handling. The strings come from `Resources/ar.json`, generated by `scripts/ios-strings.ts` |
| `Shell/` | the web's phone shell: top bar, floating tab bar with the centre +, Create sheet, drawer, app switcher, full-screen search |
| `One/<area>/` | the Maham One screens, one folder per web area (Home, Sales, Purchases, Items, Accounting, Banking, Reports, People, Payroll, Compliance, CRM, Files, Approvals, Settings) |
| `Tasks/` | the Maham Tasks department (today's native screens, until its own parity stage) |

## Contracts between the parts

These are the shared interfaces. Don't change them without updating this file.

```swift
// Localization (App/Localization)
func t(_ key: String, _ vars: [String: String] = [:]) -> String   // web t(key, vars)
func tp(_ count: Int, _ one: String, _ other: String, _ vars: [String: String] = [:]) -> String
@MainActor @Observable final class LanguageStore {
  static let shared: LanguageStore
  var language: Language               // .en, .ar; saved; drives layoutDirection
  var isArabic: Bool { get }
}

// Design system (App/DesignSystem)
@MainActor @Observable final class ThemeStore {
  static let shared: ThemeStore
  var mode: ThemeMode                  // .light, .dark, .system
  var lightTheme: ThemeID              // default .classic
  var darkTheme: ThemeID               // default .midnight
  func palette(for scheme: ColorScheme) -> Palette
}
struct Palette {                       // one theme's variables, named as on the web
  func color(_ token: Token) -> Color  // .primary(600), .slate(900), .surface, .page, .shell, .primarySolid, .onPrimary, .red(50), …
}
extension View { func webTheme() -> some View }   // the palette, fonts and layout direction for a screen tree
// Read the palette in views with @Environment(\.palette).

// Liquid Glass (App/DesignSystem/WebGlass.swift; the owner's choice on top of the web's look).
// Buttons and the floating bars are glass; cards, lists, inputs and text stay the web's.
.buttonStyle(.web(.primary, .md))            // WebButton's look: glass in the variant's colours
.buttonStyle(.webGlass(.circle))             // glass behind a custom label (.rounded(r), tint:)
GlassIconButton(.x, label: t("Close")) { … } // a 44pt glass icon button with a haptic
// Inside a glass bar (StickyActions) `webButtonOnGlass` is set: clear buttons take a fill.

// Haptics (App/System/Haptics.swift): every haptic at 50% of its usual strength.
// Never use .sensoryFeedback or UIKit's generators directly.
enum Haptic { case tap, press, selection, toggle, change, open, close, refresh, success, warning, error }
@MainActor enum Haptics {
  static func play(_ haptic: Haptic)
  static func prepare(_ haptic: Haptic = .tap)   // as a control is pressed
  nonisolated static func refresh() async        // first thing in .refreshable
}
extension View {
  func haptic<T: Equatable>(_ haptic: Haptic, trigger: T) -> some View   // also (_:trigger:condition:), (trigger:_:)
}
// WebButton, GlassIconButton, ListRow, DropdownItem, Segmented, Switch, Select, Combobox,
// DateField, the toasts and WebPage(refresh:) play theirs already.

// Money and format (MahamKit/Foundation)
public enum Money {
  static func dec(_ value: Double) -> Decimal      // via the shortest string, like JS String(n)
  static func round(_ value: Decimal, _ places: Int) -> Decimal   // half away from zero, no -0
  static func precision(_ currency: String) -> Int
}
public enum Format {
  static func money(_ amount: Decimal, currency: String, locale: FormatLocale) -> String  // "KD 1,234.500" / "1,234.500 د.ك"
}
```

## Stages

0. **Foundations:** design system, shell, strings, formatting, raw records, roles, and the
   sync engine, which reads everything and writes nothing yet.
1. **Sales:** invoices, quotes, credits, proformas, sales orders, delivery notes, recurring,
   payments received, clients.
2. **Purchases:** vendors, bills, vendor credits, purchase orders, expenses, payments made,
   cheques.
3. **Items and inventory.**
4. **Accounting:** accounts, journals, banking, VAT, assets, year end, reports, dashboard.
5. **People and payroll:** employees, payroll, leave, loans, settlements, letters, costing.
6. **Compliance, CRM, files, approvals, updates, settings, templates, PDFs and printing.**
7. **Maham Tasks**, screen for screen with tasks.mahamone.com.

Each stage ships to TestFlight. A stage's records become writable only when its rules pass
the web's test cases.
